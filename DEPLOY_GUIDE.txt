FILES YOU NEED (all 5)

  packages.txt       ← system dependencies
  DEPLOY_GUIDE.txt   ← this file


PART 1 — UPLOAD TO GITHUB
════════════════════════════════════════════════════════════

1. Go to github.com and log in
2. Open your repository (pe-portfolio-finder)
3. Delete ALL old files if any exist
4. Click "Add file" → "Upload files"
5. Drag and drop all 5 files
6. Click "Commit changes"


PART 2 — ADD YOUR GEMINI API KEY TO STREAMLIT
════════════════════════════════════════════════════════════

IMPORTANT: Never paste your API key in chat or email.
Store it safely in Streamlit Secrets only.

1. Go to streamlit.io and log in
2. Click your app
3. Click "Manage app" (bottom right corner)
4. Click "Settings"
5. Click "Secrets"
6. Type exactly this (replace with your real key):

   GEMINI_API_KEY = "AIzaSy...your-key-here..."

7. Click "Save"


PART 3 — DEPLOY / REBOOT
════════════════════════════════════════════════════════════

If deploying fresh:
1. Click "New app" on Streamlit
2. Select your GitHub repository
3. Main file: app.py
4. Click "Deploy"
5. Wait 3-5 minutes

If rebooting after file changes:
1. Click "Manage app"
2. Click "Reboot app"
3. Wait 2-3 minutes


PART 4 — SHARE WITH YOUR TEAM
════════════════════════════════════════════════════════════

Copy the URL from your browser and send it to anyone.
They just open it — no login, no install needed.

COMMON PROBLEMS
════════════════════════════════════════════════════════════

"Gemini API key not found"
→ Go to Streamlit → Manage App → Settings → Secrets
→ Add: GEMINI_API_KEY = "your-key-here"

"Error installing requirements"
→ Make sure packages.txt is uploaded to GitHub

App crashes on startup
→ Make sure all 5 files are uploaded
→ Check packages.txt is there

Search returns 0 results
→ Try a shorter firm name e.g. "KKR" not "KKR & Co. Inc"
→ Some sites block automated browsers
